# distance · 경로노트

출발지·도착지 주소를 엑셀로 불러와 도로거리와 경로를 확인하는 정적 웹 앱입니다.

## 기능

- 대상: 안산시 단원구·상록구, 시흥시 정왕동 (대부도 제외)
- XLSX·CSV 불러오기, 시트 선택, 출발지·도착지 열 인식
- 주소검색 결과 확인, 지도에서 위치 지정·수정
- 자동차 편도 도로거리(km)와 경로 표시
- 지도 JPG가 삽입된 결과 엑셀과 상세 결과 시트
- 선택 구간의 지도 JPG 개별 저장
- 엑셀과 구간별 지도 JPG를 한 ZIP으로 저장 (최대 200개 지도)

## Android 앱

웹주소를 열지 않고 실행되는 Android 프로젝트가 포함되어 있습니다. APK 생성·설치 방법은 [ANDROID.md](ANDROID.md)를 확인하세요. GitHub Actions의 **Android APK**에서 설치 확인용 APK를 생성합니다.

## 실행

서버나 API 키 없이 정적 파일로 실행합니다. 프로젝트 루트에서:

```sh
python3 -m http.server 8080 --directory dist
```

브라우저에서 http://localhost:8080 으로 접속합니다. 파일을 직접 더블클릭하는 file:// 방식은 지원하지 않습니다.

정적 호스팅에 올릴 때는 `dist` 폴더를 공개 폴더로 지정합니다. 빌드 단계는 필요하지 않습니다. 저장소 업로드만으로 호스팅이 자동 설정되지는 않습니다.

### Vercel 배포

저장소를 가져올 때 **Root Directory는 `./`**, **Application Preset은 `Other`**로 둡니다. 루트의 `vercel.json`이 공개 폴더를 `dist`로 지정하며, 설치와 빌드 단계는 생략합니다. 환경변수는 필요하지 않습니다.

기존 배포에서 404가 표시됐다면 이 설정 파일이 포함된 최신 main으로 재배포합니다. 프로젝트를 다시 만들 필요는 없습니다.

### Netlify 배포

GitHub 저장소를 연결한 경우 루트의 `netlify.toml`이 공개 폴더를 `dist`로 지정합니다. Base directory는 저장소 루트(`.`), Publish directory는 `dist`, Build command는 비워 둡니다. Android 빌드는 웹 배포에 필요하지 않습니다.

기존 배포에서 404가 표시됐다면 최신 main으로 다시 배포한 뒤 Netlify에 표시되는 현재 운영 사이트 주소를 여세요. 이전 배포 전용 주소는 새 배포로 바뀌지 않습니다.

폴더를 직접 업로드하는 수동 배포에서는 `dist` 폴더를 업로드하세요. 업로드할 폴더를 열었을 때 바로 `index.html`, `app.js`, `style.css`, `vendor`가 보여야 합니다. 저장소 전체나 Android 프로젝트를 업로드하면 첫 화면을 찾지 못할 수 있습니다.

## 지도 이미지 용량

새 지도는 JPG로 저장하며 장당 200~300KB를 목표로 압축합니다. 품질을 먼저 조절하고 필요한 경우 해상도를 낮춰 최대 300,000바이트로 제한합니다. 단순한 지도는 200KB보다 작을 수 있으며 용량을 맞추려고 불필요하게 늘리지 않습니다. 엑셀 삽입 그림, 개별 JPG와 ZIP의 지도는 동일한 압축 이미지를 사용합니다. 지도 200장 자체는 최대 약 60MB이며, 지도 포함 엑셀을 함께 담은 ZIP 전체는 이보다 큽니다.

## 사용 순서

1. 엑셀 양식을 내려받아 `출발지`, `도착지` 열에 주소를 입력합니다.
2. 파일을 불러오면 최대 200구간의 주소를 순서대로 좌표로 변환하고 번호별 핀을 표시합니다. 이 단계에서는 거리 계산을 하지 않습니다. `좌표 엑셀 저장`으로 위도·경도 결과를 바로 저장할 수 있습니다.
3. 정확한 주소·번호 또는 장소명이 일치하는 단일 후보만 자동 표시합니다. 핀 위치를 확인하고 미변환 주소는 지도에서 직접 지정한 뒤 **전체 거리 계산**을 누르세요. 검색 실패나 경로 오류가 있는 구간은 나머지 계산을 막지 않습니다. 중지 후 다시 누르면 완료 결과를 유지하고 나머지를 처리합니다.
4. 경로 그림까지 저장하려면 거리 계산 후 `지도 포함 엑셀 저장` 또는 `엑셀·지도 ZIP 저장`을 누릅니다.
5. 파일 생성이 끝나면 `파일 내려받기`를 누릅니다. 지원하는 기기에서는 `공유·파일에 저장`도 사용할 수 있습니다.

선택하지 않은 구간의 지도 그림이 아직 준비되지 않았다면 저장 화면의 안내에 따라 구간을 확인합니다. 계산되지 않은 행은 엑셀에 확인사항과 함께 남습니다.

### iPad에서 엑셀 지도가 비어 보일 때

엑셀 파일에는 JPG 그림이 포함되지만 일부 미리보기 앱은 삽입된 그림을 표시하지 않을 수 있습니다. Excel 앱으로 열거나 **엑셀·지도 ZIP 저장**을 사용하세요. ZIP을 파일 앱에 저장하고 압축을 풀면 다음 파일을 확인할 수 있습니다.

- `results.xlsx`: 지도 포함 엑셀 (입력한 모든 구간과 미계산 상태 보존)
- `maps/route-001.jpg` 등: 계산 완료 구간별 지도 그림. 번호는 엑셀의 구간 번호와 동일합니다.
- `index.html`: 컴퓨터 브라우저에서 여는 지도 모음. `maps` 폴더와 함께 두세요.
- `README.txt`: 저장 결과 개수와 사용 안내

미계산 구간에는 JPG가 생성되지 않습니다. 예를 들어 3번만 계산했다면 `route-003.jpg` 한 장이 들어갑니다. ZIP은 이미 압축된 XLSX와 JPG를 다시 압축하지 않고 묶습니다. 브라우저에서 추가 지도 요청 없이 준비된 그림을 사용합니다. 파일 생성 후 사용자 탭으로 다운로드·공유하므로 저장을 눌렀다는 이유만으로 기기 저장 완료라고 표시하지 않습니다.

## 지도 서비스와 한계

- OpenStreetMap 지도, Leaflet, Photon 주소검색, OSRM 자동차 경로, ExcelJS를 사용합니다.
- 공개 서버를 사용하는 소량 시험 버전으로 파일당 최대 200구간, 순차 요청을 적용합니다.
- 반복·대량 처리는 별도로 운영하는 서버 연결이 필요합니다. 연결 설정은 `dist/config.json`에 있습니다.
- 지도 그림은 사용자가 보고 있는 화면에 이미 로드된 지도 타일로 만듭니다. 보이지 않는 구간의 타일을 미리 다운로드하지 않습니다.
- 한국 주소·도로의 누락이 있을 수 있어 위치 확인이 필요합니다. 실시간 교통, 통행료, 공사·통제는 반영하지 않습니다.
- 지도 표시 범위는 정확한 행정경계와 다를 수 있습니다.
- 파일은 브라우저 메모리에서 처리됩니다. 검색 주소·경로 좌표는 외부 지도 서비스에 전송됩니다.
- 다운로드 호출만으로 실제 기기 저장 완료를 확인할 수는 없습니다. iPad/Safari 실기기 다운로드는 아직 검증하지 못했습니다.

## 검증

Node.js 22 이상을 사용합니다.

```sh
npm install
npm test
```

엑셀·CSV 입출력, 주소 누락, 지역 필터, 거리 결과, JPG 생성, 이미지 포함 XLSX 왕복 읽기, 그림 배치 좌표, ZIP 내부 파일·체크섬, 200구간의 JPG 개수와 원본 일치, 오래된 지도 이미지 차단, 사용자 탭을 통한 다운로드·공유를 검사합니다. 지도 렌더 테스트 배경은 모의 데이터이며 실제 경로 정확성의 검증은 아닙니다. 테스트 결과 파일은 운영체제 임시 폴더에 생성됩니다. iPad 실기기의 엑셀 미리보기 표시 여부는 별도 확인이 필요합니다.

선택적으로 `ROUTE_TEST_FONT`에 한글 폰트 파일 경로를 지정할 수 있습니다.

라이선스·지도 출처는 `dist/THIRD_PARTY.txt`와 `dist/vendor/*-LICENSE`를 참고하세요.

## 엑셀 주소 → 좌표 먼저 표시 (2026-10-28)

- XLSX/CSV 불러오기 또는 시트 선택 후 주소를 자동으로 순차 변환합니다. 이 단계에서는 도로거리 API를 호출하지 않습니다. 중지 후 `주소 → 좌표 변환`으로 이어서 처리할 수 있습니다.
- `전체 좌표 보기`는 엑셀 구간 번호와 A(출발)/B(도착) 핀을 표시합니다. 동일 좌표는 핀 하나로 묶으며 핀을 누르면 해당 구간 목록이 열립니다. 목록에서 구간을 선택하면 개별 위치 확인 화면으로 이동합니다.
- `좌표 엑셀 저장`은 번호·원본 주소·검색 주소·위도·경도·각 위치 상태·좌표 출처를 저장합니다. 거리 계산이나 지도 그림 생성 없이 저장할 수 있습니다. 기존 상세결과 열의 순서를 유지하고 추가 필드는 뒤에 붙였습니다.
- `전체 거리 계산`은 확보된 좌표를 사용해 도로거리를 계산합니다. 기존 지도 포함 엑셀·JPG·ZIP 저장은 유지됩니다. 계산 전 좌표 엑셀에는 거리 값과 경로 그림이 없습니다.
- 같은 주소는 일괄 처리 중 한 번만 검색하고, 엑셀 좌표와 직접 지정한 위치는 다시 검색하지 않습니다. 최대 200구간을 유지합니다.
- **주소 데이터 공급자는 바꾸지 않았습니다.** Photon/OSM에서 정확한 주소·번호가 확인되지 않으면 좌표를 임의 생성하지 않고 변환 실패로 남깁니다. 이 변경은 좌표 우선 작업 흐름이며, 국내 지번 데이터 보강이나 Google/Nominatim 연결은 아닙니다.

검증: `node verify-coordinates.mjs`는 200구간/400개 지점, 중복 검색 제거, CSV/XLSX 자동 시작, 부분 실패, 지도 없이 좌표 XLSX 저장·재입력을 검사합니다. `node scripts/preview-coordinates.mjs`는 UI 검사용 모의 지도·검색·거리 응답만 제공하며 실제 서비스에는 요청하지 않습니다. 배포에 쓰지 마세요.

## 주소 정확도 보호 (2026-10-28)

검색은 한국어 응답을 요청하며 한글·영문 지역명을 모두 판별합니다. 단원구·상록구로 시작하는 주소는 안산시를, 정왕동으로 시작하는 주소는 시흥시를 보완해 검색합니다. 동·도로 중심점, 주소명·번호 불일치, 여러 일치 후보는 자동 선택하지 않습니다. Photon의 housenumber만으로 국내 지번을 검증할 수 없으므로 지번 입력은 정확한 좌표가 따로 확인되지 않으면 지도 직접 지정이 필요합니다. 도로명·건물번호 또는 장소명이 일치하는 단일 후보만 자동 선택하되 사용자가 실제 위치를 확인해야 합니다. 검색 후보의 미확인 항목은 선택할 수 없습니다. 지도 직접 지정과 엑셀 좌표는 기존대로 사용할 수 있습니다. 직접 '주소 찾기'를 누르면 이전 검색 캐시를 건너뛰어 재조회합니다.

이 변경은 잘못된 자동 계산을 방지하는 조치이며 지번 데이터 자체를 보충하지 않습니다. Google 전환은 아직 적용하지 않았습니다. Google Geocoding을 사용하려면 사용자가 관리하는 결제 설정 및 제한된 API 키가 필요하고, Google 주소검색 결과를 비Google 지도에 결합하는 제한과 결과 이미지·엑셀 저장 조건을 검토한 후 별도로 전환해야 합니다. 비밀키를 저장소에 올리지 마세요.

## 미확인 주소 일괄 보정 (2026-10-28)

- `위치 미확인만 보기`로 확인할 구간을 필터링하고, `주소별 확인 목록`에서 중복 주소를 묶어 확인합니다. 주소 옆의 수는 해당 주소가 사용된 출발·도착 지점 수입니다.
- `다음 미확인 주소`를 누르면 위치가 없는 지점은 지도 지정 모드로, 자동 검색되어 확인만 필요한 지점은 위치 확인 화면으로 이동합니다.
- `지도 지정 시 같은 주소에 적용`이 켜져 있으면 한 번 찍거나 핀을 옮길 때 현재 파일의 같은 주소에 반영합니다. 시·도 표기와 공백 일부만 정규화하며 `518`, `518-1`, `산518`은 서로 다른 주소입니다. 행정동/법정동, 지번/도로명 주소를 임의로 동일시하지 않습니다.
- 별도로 확인된 좌표(예: 엑셀 좌표)는 덮어쓰지 않고 안내합니다. 이 기능으로 함께 지정된 좌표들은 이후 같은 주소를 다시 지정할 때 함께 갱신됩니다. 다른 출입구를 써야 한다면 체크를 해제하고 개별 지정하세요.
- 변경된 모든 구간의 거리·경로·지도 그림과 내려받기 대기 파일을 무효화합니다. `전체 위치 검색·거리 계산`을 누르면 기존 완료 구간은 유지하고 미계산 구간을 계산합니다.
- 한 번의 일괄 처리 안에서는 같은 주소의 빈 검색 결과도 재사용해 중복 요청을 줄입니다. 통신 오류는 재사용하지 않으며 다음 일괄 처리에서는 실패 주소를 다시 검색합니다.
- 위치 보정은 현재 불러온 파일에만 적용됩니다. 새 파일/시트에는 자동 이월하지 않습니다. 결과 엑셀의 `상세결과` 시트에는 보정 좌표가 포함되므로 해당 시트를 다시 불러와 사용할 수 있습니다.

**한계:** 이 변경은 국내 주소 DB 연결이 아닙니다. 현재 Photon/OSRM/OSM, 200구간 제한, 지도 포함 엑셀·ZIP 저장을 유지합니다. 국내 지번의 정확한 좌표를 보충하려면 이용·저장 권한이 확인된 원천 데이터나 API 승인이 필요합니다. Google 또는 국내 API 키를 임의로 활성화하지 않았습니다. 지번을 도로명이나 인근 시설 좌표로 임의 대체하지 않습니다.
