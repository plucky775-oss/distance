# distance · 경로노트

출발지·도착지 주소를 엑셀로 불러와 도로거리와 경로를 확인하는 정적 웹 앱입니다.

## 기능

- 대상: 안산시 단원구·상록구, 시흥시 정왕동 (대부도 제외)
- XLSX·CSV 불러오기, 시트 선택, 출발지·도착지 열 인식
- 주소검색 결과 확인, 지도에서 위치 지정·수정
- 자동차 편도 도로거리(km)와 경로 표시
- 지도 PNG가 삽입된 결과 엑셀과 상세 결과 시트
- 선택 구간의 지도 PNG 개별 저장

## 실행

서버나 API 키 없이 정적 파일로 실행합니다. 프로젝트 루트에서:

```sh
python3 -m http.server 8080 --directory dist
```

브라우저에서 http://localhost:8080 으로 접속합니다. 파일을 직접 더블클릭하는 file:// 방식은 지원하지 않습니다.

정적 호스팅에 올릴 때는 `dist` 폴더를 공개 폴더로 지정합니다. 빌드 단계는 필요하지 않습니다. 저장소 업로드만으로 호스팅이 자동 설정되지는 않습니다.

### Vercel 배포

저장소를 가져올 때 **Root Directory는 `./`**, **Application Preset은 `Other`**로 둡니다. 루트의 `vercel.json`이 공개 폴더를 `dist`로 지정하며, 설치와 빌드 단계는 생략합니다. 환경변수는 필요하지 않습니다.

기존 배포에서 404가 표시됐다면 이 설정 파일이 포함된 최신 main으로 재배포합니다. 프로젝트를 다시 만들 필요는 없습니다.

## 사용 순서

1. 엑셀 양식을 내려받아 `출발지`, `도착지` 열에 주소를 입력합니다.
2. 파일을 불러오고 주소 검색을 실행합니다.
3. 각 구간의 위치를 확인한 뒤 거리 계산을 누릅니다.
4. `지도 포함 엑셀 저장` 또는 `경로 지도 PNG 저장`을 누릅니다.

선택하지 않은 구간의 지도 그림이 아직 준비되지 않았다면 저장 화면의 안내에 따라 구간을 확인합니다. 계산되지 않은 행은 엑셀에 확인사항과 함께 남습니다.

## 지도 서비스와 한계

- OpenStreetMap 지도, Leaflet, Photon 주소검색, OSRM 자동차 경로, ExcelJS를 사용합니다.
- 공개 서버를 사용하는 소량 시험 버전으로 파일당 최대 50구간, 순차 요청을 적용합니다.
- 반복·대량 처리는 별도로 운영하는 서버 연결이 필요합니다. 연결 설정은 `dist/config.json`에 있습니다.
- 지도 그림은 사용자가 보고 있는 화면에 이미 로드된 지도 타일로 만듭니다. 보이지 않는 구간의 타일을 미리 다운로드하지 않습니다.
- 한국 주소·도로의 누락이 있을 수 있어 위치 확인이 필요합니다. 실시간 교통, 통행료, 공사·통제는 반영하지 않습니다.
- 지도 표시 범위는 정확한 행정경계와 다를 수 있습니다.
- 파일은 브라우저 메모리에서 처리됩니다. 검색 주소·경로 좌표는 외부 지도 서비스에 전송됩니다.
- 다운로드 호출만으로 실제 기기 저장 완료를 확인할 수는 없습니다. iPad/Safari 실기기 다운로드는 아직 검증하지 못했습니다.

## 검증

Node.js 22 이상을 사용합니다.

```sh
npm install
npm test
```

엑셀·CSV 입출력, 주소 누락, 지역 필터, 거리 결과, PNG 생성, 이미지 포함 XLSX 왕복 읽기 및 오래된 지도 이미지 차단을 검사합니다. 지도 렌더 테스트 배경은 모의 데이터이며 실제 경로 정확성의 검증은 아닙니다. 테스트 결과 이미지는 운영체제 임시 폴더에 생성됩니다.

선택적으로 `ROUTE_TEST_FONT`에 한글 폰트 파일 경로를 지정할 수 있습니다.
